The Golden Ladle is an original rush-kitchen cooking game that runs in a desktop browser from static files. Take orders from the board, cook patties, eggs, noodles and pancakes to the golden window, assemble each plate to match its recipe and serve before patience runs out - chain combos, hit the coin goal and earn three stars.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
